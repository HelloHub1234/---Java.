# MyGames

Пакет консольных игр на Java.

## Игры

- **Угадай число** (`Game_rand`) — загадывается случайное число в диапазоне, игрок вводит варианты, пока не угадает. Подсчитывается количество попыток.
- **Камень, ножницы, бумага** (`Game_kmn`) — классическая игра против бота. Игрок выбирает количество раундов (1, 3 или 5). Используется вспомогательный класс `Check` для определения исхода раунда.
- **Угадай, в какой коробке Verity** (`Game_box`) — игрок угадывает, в какой из коробок спрятана Verity. С ростом уровня увеличивается количество коробок.

## Структура

- `Basic_class.java` — базовый класс с общей логикой: печать заголовка, подсчёт очков, запрос на повтор игры, прощание.
- `Check.java` — утилита для определения результата раунда в «Камень, ножницы, бумага».
- `Game_box.java`, `Game_kmn.java`, `Game_rand.java` — конкретные реализации игр.

## Запуск

Скомпилируйте и запустите нужный класс из пакета `MyGames`, например:

```bash
javac MyGames/*.java
java MyGames.Game_rand
```

Или используйте вашу IDE (IntelliJ IDEA, Eclipse и др.).
